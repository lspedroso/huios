# HUIÓS — Filhos Maduros

Site de inscrições em React (Vite) com landpage, menu hambúrguer, carrossel, login e footer.

## Rodar localmente

```bash
cd Me/huios
npm install
npm run dev
```

O hero usa [`@shadergradient/react`](https://www.shadergradient.co/) com o preset **sunset**, nas cores `#F26E22`, `#0D0D0D` e `#8B3A12`.

## Personalizar

- **Fotos do carrossel:** coloque as imagens em `assets/` (ex.: `foto 1.jpg`). O carrossel carrega automaticamente e fica em loop.
- **Telefone e Instagram:** edite `src/components/Footer.jsx`.
